# Контракты

Источник истины: `src/hopiumcode/models.py` (данные) и `src/hopiumcode/interfaces.py` (интерфейсы).
Идентификатор фрагмента: `path::qualified_name` или `path::#N`. Формат ссылки в ответе: `[путь:начало-конец]`.
Типы узлов графа: File, Class, Function, Doc. Типы рёбер: DEFINES, CALLS, IMPORTS, INHERITS, DOCUMENTS.

## Идентификаторы фрагментов (Chunk.id) и узлов графа

Id фрагмента совпадает с id узла графа (проверяется тестом `test_chunk_ids_match_graph_nodes`), поэтому
обход графа находит нужные фрагменты.

| Что | Id | Примечание |
|---|---|---|
| функция, метод, класс | `path::Qualified.name` | класс: только заголовок (докстринг и атрибуты), методы отдельными фрагментами |
| код верхнего уровня модуля | `path` | совпадает с узлом File; диапазон строк от первой до последней строки такого кода |
| раздел .md/.rst | `path::#N` | N с нуля, нумерация та же, что в графе |
| .txt | `path::#0` | целиком |
| продолжение длинного фрагмента | `<id>~2`, `<id>~3`, … | фрагменты длиннее ~300 токенов (слов*1.5) режутся по пустым строкам, перекрытие 2 строки |
| повторное определение имени | `<id>@2`, `<id>@3`, … | `property.setter`, ветки `if/else`; в графе такие определения сливаются в один узел |

Номера строк во всех фрагментах настоящие (по файлу), кроме модульного: он собирается из строк вне
определений, поэтому его диапазон может охватывать и функции.
