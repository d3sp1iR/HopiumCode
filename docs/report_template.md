# Итоговый отчёт: HopiumCode, локальный ИИ-агент для онбординга в кодовую базу

Команда CopiumCore. Шаблон: все места с «ВСТАВИТЬ РЕЗУЛЬТАТ» заполняются из реальных прогонов
(`eval/results/<дата-время>.json` и `.md`), числа не придумываются.

## 1. Цель

- Задача: агент отвечает на вопросы разработчика по незнакомому репозиторию и подкрепляет каждое
  утверждение ссылкой `[путь:начало-конец]`; работает локально, без внешних API.
- Репозиторий-цель: Flask 3.1.3, коммит `22d924701a6ae2e4cd01e9a15bbaf3946094af65`, индексируется `src/flask`.
- Критерии успеха: ВСТАВИТЬ РЕЗУЛЬТАТ (согласованные с командой пороги recall@k, доли подтверждённых ссылок, answered).

## 2. Архитектура

- Схема: `docs/architecture.mmd` / `docs/architecture.puml` (вставить отрендеренную картинку).
- Индексация: loader → chunker → embed → Chroma; chunker → BM25; loader → graph.extract → graph.store.
- Запрос: orchestrator → retrieval.hybrid → prompts → Ollama → (tool_call → MCP) → verify_citations.
- Контракты: `src/hopiumcode/models.py`, `src/hopiumcode/interfaces.py`, `docs/contracts.md`.
- Принятые решения: `docs/decisions.md`.

## 4. Метод оценки

- Набор: `eval/questions.yaml`, 32 вопроса: 10 semantic, 10 graph, 5 overview, 5 history, 2 trap.
  Эталоны (файлы, символы, диапазоны строк, коммиты) проверены по коду; `tests/test_eval_questions.py`.
- Режимы retrieve: vector, vector+bm25, hybrid (`make eval ARGS="--mode all"`).
- Метрики: recall@5, recall@8 (по первому вызову retrieve), доля подтверждённых ссылок, answered
  (для trap: «не нашёл» без ссылок), время ответа, число шагов модели; вспомогательно LLM-судья 0/1/2 (`--judge`).
- Условия прогона: модель ВСТАВИТЬ РЕЗУЛЬТАТ, температура 0, железо ВСТАВИТЬ РЕЗУЛЬТАТ, дата и коммит
  HopiumCode ВСТАВИТЬ РЕЗУЛЬТАТ, файл результатов ВСТАВИТЬ РЕЗУЛЬТАТ.

## 7. Ограничения

- Проверка ссылок подтверждает пересечение диапазона с найденным контекстом, но не верность утверждения.
- recall@k не учитывает то, что агент нашёл инструментами после первого retrieve.
- LLM-судья — та же модель, что и отвечающая; оценки вспомогательные.
- Набор вопросов небольшой (32) и составлен командой; ВСТАВИТЬ РЕЗУЛЬТАТ (другие ограничения по итогам прогонов).
